# React Movie Site

A movie discovery web application built with React while following a tutorial from JavaScript Mastery.

## Overview

This project is a modern movie site that allows users to browse and explore movies using a clean, responsive UI. It was built as part of a learning journey to strengthen frontend development skills and understand full-stack integration.

## Tech Stack

* React (JavaScript)
* Tailwind CSS
* Appwrite (Backend as a Service)
* Vite (Build tool)

## Features

* Browse trending and popular movies
* Search functionality
* Responsive UI for mobile and desktop
* Fast performance with Vite
* Backend integration using Appwrite

## Purpose

This project was built while following a tutorial by JavaScript Mastery to practice:

* React component architecture
* API integration
* State management
* Backend integration with Appwrite
* Styling with Tailwind CSS

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/shina-wq/react-movie-site.git
cd react-movie-site/vite-project
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start development server

```bash
npm run dev
```

### 4. Build for production

```bash
npm run build
```

## Environment Variables

Create a `.env.local` file:

```env
VITE_APPWRITE_PROJECT_ID=your_project_id
VITE_APPWRITE_DATABASE_ID=your_database_id
VITE_APPWRITE_TABLE_ID=your_table_id
VITE_APPWRITE_ENDPOINT=your_endpoint
```
